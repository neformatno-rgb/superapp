# Кабинет перевозчика — веб-прототип

Кликабельный прототип мобильного приложения для перевозчиков: поиск грузов, заявки, перевозки, отслеживание.

**Открыть:** https://neformatno-rgb.github.io/superapp/

Удобнее всего смотреть с телефона или в узком окне браузера. Сборка не нужна: обычные HTML, CSS и JS без зависимостей. Данные демо-режима хранятся в localStorage браузера.

## Структура

```
index.html                 разметка-каркас, подключает стили и скрипты
css/
  main.css                 точка входа: @import всех файлов в порядке каскада
  tokens.css               цвета, шрифты, радиусы; светлая и тёмная темы
  base.css                 сброс, safe-area, базовая типографика, иконки
  layout.css               каркас страницы, колонка, карточки, пустые состояния
  components/              стили отдельных компонентов (кнопки, чипы, теги,
                           формы, таймлайн, шторки, карта, нижнее меню и т. д.)
  views/                   стили конкретных экранов
js/
  core/                    иконки, утилиты, состояние, роутер
  data/                    демо-данные: грузы, способы оплаты, карта, генератор грузов
  components/              переиспользуемые блоки: карточки, таймлайн, карта, шторки, тосты
  features/                поиск и фильтры, выбор дат и кузова, допы в заявке,
                           копирование координат
  views/                   экраны: главная, поиск, заказ, оформление, перевозки, рейс, карта, меню
  app/                     рендер, обработчики событий, жесты карты, всплывающее меню
  main.js                  запуск приложения
assets/img/                картинки
```

Скрипты обычные (не модули) и подключаются с `defer` в порядке зависимостей. Так приложение открывается и с GitHub Pages, и локально из папки.
